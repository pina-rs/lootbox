# Security Policy

Lootbox is pre-release software and has not been deployed to mainnet by this repository.

Please do not open a public issue for a suspected vulnerability. Send a private report through GitHub Security Advisories for `pina-rs/lootbox` and include:

- affected commit and component;
- impact and realistic attack prerequisites;
- reproduction steps or a minimal test;
- any proposed mitigation.

Avoid testing against accounts or funds you do not own. We will acknowledge a complete report, assess severity, prepare a regression test and fix, and coordinate disclosure after users have a reasonable upgrade window.

The current internal threat analysis and unresolved production gates are documented in [docs/security-review.md](docs/security-review.md).
